# Car Management System 🚗💨

A web-based platform for managing and showcasing premium supercars, featuring a video background for a dynamic user experience.

## Live Demo

Check out the live site here: https://akhilesh27nr.github.io/car-management/ 
> **Note:** The site is hosted on GitHub Pages and is completely safe. Some browsers may warn about `.io` domains, but this is a false positive.
